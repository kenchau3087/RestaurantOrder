# RestaurantOrder
Practice for full stack development

A full-stack web application built to handle restaurant menu browsing and real-time kitchen order management. 

## 🚀 Tech Stack
* **Frontend:** React JS, React Router, CSS-in-JS
* **Backend:** C# ASP.NET Core Minimal API, Entity Framework Core (Pomelo)
* **Database:** MySQL
* **Tools:** Git, Vite, RESTful APIs

## ✨ Features
* **Customer Dashboard:** Browse menu items, add to cart, and calculate totals.
* **Kitchen Dashboard:** Real-time view of incoming orders using polling.
* **State Management:** Seamless transitions from 'Pending' to 'Served'.
* **Relational Database:** Separated Menu Items and Orders tables for data integrity.
